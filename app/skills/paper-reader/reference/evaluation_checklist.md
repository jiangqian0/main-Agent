# 论文评估清单

## 一、研究问题

- [ ] 研究问题是否清晰明确？
- [ ] 问题的动机和重要性是否充分说明？
- [ ] 研究问题是否有创新性或独特视角？

## 二、创新性

- [ ] 相比现有工作有什么新贡献？
- [ ] 是新问题、新方法还是新视角？
- [ ] 创新点是否足够显著？

## 三、技术质量

- [ ] 方法描述是否清晰详细？
- [ ] 技术推导或算法是否正确？
- [ ] 假设条件是否合理？

## 四、实验评估

- [ ] 实验设置是否合理？
- [ ] 对比基线是否足够先进？
- [ ] 结果分析是否深入？
- [ ] 是否进行消融实验？
- [ ] 实验可复现性如何？

## 五、写作质量

- [ ] 逻辑结构是否清晰？
- [ ] 语言表达是否准确？
- [ ] 图表是否清晰易懂？
- [ ] 相关工作讨论是否充分？

## 六、局限性

- [ ] 论文是否讨论了局限性？
- [ ] 方法的适用范围和边界？
- [ ] 未来改进方向？

## 评分标准

| 分数 | 等级 | 说明 |
|------|------|------|
| 9-10 | 顶级 | 极重要的突破性工作 |
| 7-8 | 优秀 | 重要的贡献，值得关注 |
| 5-6 | 良好 | 不错的 工作，可以借鉴 |
| 3-4 | 一般 | 贡献有限，可略读 |
| 1-2 | 较差 | 问题较多，不推荐 |

## 快速判断

如果满足以下任意条件，建议深入阅读：
- 来自顶级会议/期刊
- 作者是领域知名研究者
- 引用数较高
- 与自己的研究高度相关
